# **App Name**: Nahrain Shop

## Core Features:

- RTL-Optimized Architecture: A high-performance Next.js layout designed specifically for Right-to-Left (RTL) Arabic text flow to ensure a native shopping feel.
- Dynamic Product Discovery: A Firestore-integrated product grid that displays inventory with real-time updates and lazy loading for high performance.
- Smart Search Tool: An AI-powered search tool that understands Iraqi dialect nuances to help customers find products quickly based on intent.
- Curated Category Navigation: Visual, icon-rich category slider that allows users to navigate major shopping departments with a single tap.
- App-Like Bottom Nav: Mobile-optimized bottom navigation bar providing quick access to home, search, categories, and account, mimicking native app experiences.
- AI Trend Analysis Tool: A backend feature that uses generative models as a tool to suggest 'Trending in Iraq' product bundles based on seasonal regional data.

## Style Guidelines:

- Primary Color: Royal Blue (#2563EB), evoking trust and modernity in a corporate Arabic setting.
- Background Color: Arctic Mist (#F8FAFC), a cool-toned off-white that creates a spacious, premium retail environment.
- Accent Color: Deep Navy (#1E3A8A), used for call-to-action buttons to ensure high visibility against the light backdrop.
- Headline and Body: 'Inter', a grotesque-style sans-serif with a machined, objective, neutral look perfect for clean modern ecommerce interfaces.
- Lightweight, 2px stroke weight line icons from the Lucide set, mirroring modern mobile OS styles.
- Responsive grid system with a fixed bottom navigation on mobile devices and a sticky header for desktop users.
- Gentle spring animations for card hover effects and slide-in transitions for side menus to create a fluid, tactile app-like feeling.
